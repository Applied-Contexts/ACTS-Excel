# ACTS Excel

Build, test, and release on local or developer-managed machines. Never add or use GitHub Actions or GitHub-hosted CI. GitHub hosts source, pull requests, tags, and release assets.

Follow the local build and release commands in CONTRIBUTING.md. When asked to cut a release, complete verification, tagging, asset upload, and publication; a merged pull request is not a released version. Keep release notes explicit about which platforms were actually execution-tested.
